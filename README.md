# Backend Practice Projects 🚀

A collection of various backend and full-stack projects built for practice and learning. 

## 📂 Projects Directory

### 1. [SpendWise Expense Tracker](./expense-tracker/) 🌟 (Latest)
A premium, full-stack expense tracking application featuring a modern glassmorphic dark-themed UI.
- **Frontend**: Next.js 16, Tailwind v4, Zustand, Framer Motion, Recharts
- **Backend**: Node.js, Express, MongoDB, Zod validation, Rate Limiting, Helmet
- **Features**: JWT Authentication (Access/Refresh tokens), full CRUD for expenses, data visualization, cross-site cookie deployment support.
- [View full Expense Tracker Readme](./expense-tracker/README.md)

### 2. [Calculator CLI](./Calculator%20CLI/)
A small interactive command-line calculator built with Node.js. It provides basic arithmetic operations via a simple menu-driven interface.
- **Tech**: Node.js (readline/promises), Chalk
- **Features**: Menu-based interactive CLI, Input validation, Error handling.

### 3. Todo App
*(Located in `/Todo-app`)* - A backend practice project for managing tasks.

### 4. Weather API & App
*(Located in `/weather-api` and `/weather-app`)* - Projects focused on fetching, handling, and displaying weather data from external APIs.

## 🛠️ Global Prerequisites
Most projects require:
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/) or another package manager
- (For full-stack apps) A local or cloud [MongoDB](https://www.mongodb.com/) database
